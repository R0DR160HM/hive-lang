# Hive builds Hive, so a build needs a Hive compiler to start from, and this
# says which: the workflow downloads this asset from this release, checks it
# against this digest, and builds `src/hivec.hive` with it. Then it builds it
# again with what came out, because the first result is Go the *previous*
# compiler wrote.
#
# It is pinned rather than "latest" for the reason `src/vendor.hive` pins
# three.js: a release asset can be replaced under its own tag, and a bootstrap
# that can be moved under you is not a bootstrap. A digest that does not match
# fails the build; it is never used and never cached.
#
# To move it forward: publish a release (a tag push does that from the binaries
# the build produced), then edit the three lines below to name it. That is the
# whole of advancing the seed — see README.md in this directory.
#
# `tag: latest` is understood, and means the most recent release. It costs the
# reproducibility above, so it is not what this says.
