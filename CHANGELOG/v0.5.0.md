# v0.5.0

## Language

* **Binary values and patterns are written `<<<...>>>`**, so `<<` and `>>` are only ever shifts and a shift inside one needs no parentheses: `<<<x >> 4, y>>>`.
* **`map`, `filter` and `filterMap` take a `proc` as readily as a `func`**, as long as it does not take its element `mut`.
* **`hive.map.set` and `hive.map.delete` are declared as the `proc`s they are**, taking their map `mut`.
* **A `T[dyn]` parameter takes only a vector declared `[dyn]`**, `mut` or not; `T[]` is the parameter for any length, and the library's and Go functions' vector parameters are `T[]`.

## Breaking

| was | is |
| --- | --- |
| `<<a, b: UInt16>>` | `<<<a, b: UInt16>>>` |
| `x is <<v: UInt4, ...rest>>` | `x is <<<v: UInt4, ...rest>>>` |
| a static vector or a literal passed to a `T[dyn]` parameter | the parameter is `T[]`, or the vector is declared `[dyn]` |
