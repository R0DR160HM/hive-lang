# v0.5.1

## Language

* **`f(x) with compiler` runs a call while the program builds** and builds its answer into the executable, so reading it costs nothing at run time. Only the entrypoint may write one, its arguments are literals or other such calls' answers, and a panic in it is a compile error at the call.
* **`trim(str)` is a builtin**, answering with the string less the white space at both ends.
