# v0.5.2

## Language

* **A `mut` argument is lent, not copied, to a callee that can keep none of it** — no `mut` parameter, no thread, no function in its answer — and the answer is copied instead where it could hold that storage and weighs less.

## Tooling

* **`hive test` runs multiple tests in parallel (or concurrently if you set N higher than your available core count)**. By default, it uses as many threads as your machine has cores, but you can change the number with `--threads N`.
* **Large programs compile significantly faster**: the compiler builds itself in seconds rather than minutes.
  * The compiler's passes stopped deep-copying the whole symbol table at every lookup, through the lent arguments above.
  * `indexOf` over `Str` and `Int` vectors compares directly instead of through reflection, in every program.
  * A program with no `with compiler` call skips working out the order such calls run in.
  * Types and callables are looked up by name in an index rather than a scan.
  * Walking the storage a type reaches stops at a shape it has already been through.
  * A build asks `go env` once instead of up to four times.
* **`hive analyze` reports the copies the compiler really makes**, in seconds rather than minutes on large programs: it names an answer copied in place of its arguments, no longer charges a `Result` for a copy that never happens, and counts the copy of a `mut` name bound twice in one body.

## Breaking

| was | is |
| --- | --- |
| two tests in one program writing the same file | a file of each test's own, or `hive test --threads 1` |
| a test relying on the node another one listens on, or a service name it registers | one test doing both, or `hive test --threads 1` |
