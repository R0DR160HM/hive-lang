# v0.3.8

## Standard library

* **`hive.net.httpWsServe(port, handler, wsHandler)`** serves HTTP and WebSockets on one port: every request reaches `handler` as under `httpServe`, and answering 101 hands that one to `wsHandler`, which takes it as under `wsServe`.
* **A `hive.net.WsConnection` says who is at the far end**: `conn.address` is its `host:port`, and `hive.net.WsConnection(address)` builds one with no socket behind it, for a test.
* **`hive.sql.run` prepares a statement once** and runs that one from then on, where the database parsed its text again on every call — about half of what a short SQLite statement cost. `hive.sql.raw` is not prepared.

## Fixes

* **A `query` with a row type can be run from a `test`**: its row mapper was written only where the program itself ran the query, and a test that ran one nothing else did failed in Go with `undefined: sqlFields_…`.
* **A hole's name may open with `_`**, as any binding's may: `"{_before is (\s*)}"` was refused.

## Tooling

* **`hive container` reads the port `httpWsServe` serves**, as it does the other servers'.
